# نظام التوصيات الإسلامي ومساعد بينانس اليدوي - الإصدار الثاني (متعدد القنوات)

تحديث شامل للنظام يتيح لك **مراقبة عدد غير محدود من قنوات التوصيات** في وقت واحد، مع توفير **حقل إدخال في لوحة تحكم ويب عربية** بالإضافة إلى **أوامر تيليجرام المباشرة** لإضافة اسم القناة أو رابطها وتخزينها دائماً في النظام دون الحاجة لإعادة تشغيل البوت.

---

## ✨ المميزات الجديدة في الإصدار الثاني (v2)
1. **دعم تعدد القنوات (Multi-Channel Support):** تخزين جميع القنوات في قاعدة بيانات محلية (`channels.json`) ومراقبتها في آنٍ واحد.
2. **حقل إضافة قناة عبر واجهة ويب عربية (`web_panel.py`):**
   - بمجرد تشغيل النظام، تفتح لوحة تحكم على المتصفح (`http://127.0.0.1:5000`).
   - تحتوي على **حقل مخصص** تضع فيه **اسم القناة أو رابطها** (`https://t.me/...` أو `@ChannelName` أو رقم القناة) وتضغط حفظ ليتم تخزينها ومراقبتها فوراً.
3. **إضافة القنوات مباشرة عبر محادثة تيليجرام:**
   - أرسل `/add https://t.me/ChannelName` لإضافة قناة وتخزينها فوراً.
   - أرسل `/channels` لعرض قائمة القنوات المخزنة.
   - أرسل `/del @ChannelName` لحذف قناة من النظام.
4. **توضيح مصدر التوصية:** يظهر في إشعار الصفقة اسم القناة التي التُقطت منها التوصية لتمييز أداء كل قناة.

5. **التحقق من المشروعية عبر بوت تيليجرام:** أدخل اسم البوت من حقل "بوت الفحص الشرعي" في لوحة الويب (أو بالأمر `/bot @اسم_البوت`)، فيرسل النظام رمز العملة للبوت من حسابك ويقرأ رده (مباحة / غير مباحة) ويحفظ الحكم لمدة `HALAL_CACHE_DAYS` يوماً. العملات المضافة يدوياً للقائمة البيضاء تُعتمد مباشرة دون سؤال البوت. لفحص عملة يدوياً أرسل `/check SOL`.
6. **عرض الصفقات المباحة في الصفحة:** كل صفقة مستخرجة تُحفظ في `signals.json` وتظهر الصفقات المباحة في جدول أعلى لوحة الويب (يتحدث تلقائياً كل 15 ثانية)، والمرفوضة في قسم منفصل للمراجعة.
7. **انضمام تلقائي للقنوات:** القنوات المضافة من لوحة الويب أو بأمر `/add` (بما فيها روابط الدعوة الخاصة `t.me/+...`) ينضم إليها الحساب تلقائياً، وتظهر حالتها في جدول القنوات.

---

## 🚀 خطوات التشغيل السريع

1. **تثبيت المكتبات المحدثة:**
   ```bash
   pip install -r requirements.txt
   ```
2. **إعداد ملف `.env`:**
   انسخ `.env.example` إلى `.env` وأدخل بيانات حسابك (`TG_API_ID`, `TG_API_HASH`, `TG_BOT_TOKEN`, `ADMIN_CHAT_ID`).
3. **تشغيل النظام الكامل (البوت + لوحة الويب معاً):**
   ```bash
   python main.py
   ```
4. **فتح حقل إضافة القنوات في المتصفح:**
   افتح الرابط التالي في متصفحك لإضافة القنوات والعملات المباحة بسهولة:
   `http://127.0.0.1:5000`

---

## ☁️ الرفع على استضافة

1. **احمِ اللوحة بكلمة مرور:** اضبط `PANEL_PASSWORD` في `.env`، وإلا يستطيع أي شخص يعرف الرابط تعديل القنوات وبوت الفحص.
2. **تسجيل دخول حساب تيليجرام لأول مرة:** عند أول تشغيل يطلب Telethon رقم الهاتف ورمز التحقق، لذلك:
   - إما أن تشغّل `python main.py` مرة واحدة على السيرفر عبر SSH وتدخل الرمز،
   - أو تشغّله على جهازك ثم ترفع الملف `crypto_listener_session.session` مع المشروع.
3. **استضافة بقرص دائم:** النظام يحفظ القنوات والإعدادات والصفقات في ملفات JSON داخل مجلد المشروع، فاستخدم VPS أو استضافة تحفظ الملفات بين إعادة التشغيل.
4. **التشغيل المستمر:** شغّل `python main.py` كخدمة دائمة (مثل `systemd` أو `pm2` أو `screen`) لأن مستمع تيليجرام ولوحة الويب يعملان في نفس العملية.
